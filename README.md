# Netflix Data Filtering Using Python and Pandas

## Project Overview
This project focuses on practicing **data filtering techniques using Python and Pandas** with a Netflix dataset. The exercises explore how to extract specific records based on multiple conditions, including movie genres, release years, countries, and durations.

## Concepts and Skills Practiced

- **DataFrame Filtering (`.loc[]`):** Selecting records that meet specific conditions.
- **Logical Operators (`&`, `|`):** Combining multiple filtering conditions using AND and OR.
- **Comparison Operators (`==`, `>`, `<`, `>=`, `<=`):** Filtering numerical and categorical data.
- **Multiple Conditions:** Applying combined filters to identify movies based on genre, duration, release year, and country.
- **Membership Filtering (`.isin()`):** Selecting records that match multiple values within a column.
- **Logical Operator Precedence:** Using parentheses to ensure accurate filtering expressions.
- **Data Validation:** Using `.head()`, `.shape`, and `.unique()` to inspect and verify filtering results.

## Key Learning Outcomes

Through these exercises, I strengthened my understanding of conditional filtering, combining logical expressions, and working with Pandas DataFrames. I also practiced identifying and correcting filtering errors involving comparison operators, parentheses, and categorical values.

## Conclusion

This project contributes to my growing skills in **Python, Pandas, Data Manipulation, and Exploratory Data Analysis (EDA)**, providing a foundation for more advanced data analysis and data science projects.
